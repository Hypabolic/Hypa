# Hypa 1.0.4

Hypa 1.0.4 fixes cube sharing on fresh installs and restores the large startup logo in the attach client.

## Highlights

### Fixes

- **Sharing a cube works on the first attempt after a fresh install.**
  Share → Start now creates the certificate automatically and displays an invite code.
  Previously, it stopped with "certificate file is missing" before starting the helper that creates the certificate.
  Installed builds also now start the correct helper executable, fixing the "accept helper listen json is invalid" error.
  Later shares reuse the certificate and issue a new invite.
- **The attach client shows the large Hypa startup logo again.**
  The logo is now included in the packaged attach executable, which previously fell back to plain `HYPA` text.

## Platforms

- Linux and macOS, on x64 and arm64.
- Windows is not a mux host.

## Upgrade notes

- No manual certificate setup is needed for first-time sharing.
- After upgrading, close and reopen the attach client to use the updated sharing flow.
  A running mux keeps the binary that started it; run `hypa mux stop`, then `hypa attach`, to restart it with the new version.
- If you installed with a package manager, upgrade with `brew upgrade hypa`, `npm install --global @hypabolic/hypa`, or `pipx upgrade hypa`.
  If you installed with `install.sh`, `hypa update` upgrades in place.

Report a fault at https://github.com/Hypabolic/Hypa/issues.
